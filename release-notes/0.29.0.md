GeoPhotos 0.29.0 — the program is the same as 0.28.0; it is now built in GitHub's cloud from the public source, and you can check that.

**Install:** download `GeoPhotos-0.29.0-win-x64.zip` below, unpack it, run `GeoPhotos.exe`. The program is not signed: if Windows shows *"Windows protected your PC"*, click *More info → Run anyway*. If ExifTool is missing, click **Install for GeoPhotos** at the first start. **Update:** close GeoPhotos and unpack the new zip over the old folder; settings and ExifTool stay. Details — [Installation](https://github.com/rejgan318/geophotos#installation) in the README.

**New in 0.29.0**
- Releases are built by GitHub Actions from this repository, not on the developer's computer. GitHub attests the zip: `gh attestation verify GeoPhotos-0.29.0-win-x64.zip --repo rejgan318/geophotos` (with [GitHub CLI](https://cli.github.com/)) checks that it was built from this repository's code and not changed afterwards.
- [Building from source](https://github.com/rejgan318/geophotos#building-from-source) in the README: step by step, for those who prefer their own build.

Windows 10/11, 64-bit. Interface: English, Russian, Ukrainian.
