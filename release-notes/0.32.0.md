GeoPhotos 0.32.0 — a new Edit menu.

**Install:** download `GeoPhotos-Setup-0.32.0.exe` below and run it: it installs for you only, without administrator rights. Or take `GeoPhotos-0.32.0-win-x64.zip` and unpack it. The program is not signed: if Windows shows *"Windows protected your PC"*, click *More info → Run anyway*. If ExifTool is missing, click **Install for GeoPhotos** at the first start. **Update:** GeoPhotos 0.30.0 or later installed with the installer updates itself — the status bar says *"Version 0.32.0 is ready — restart"*. The zip version tells about it and opens this page; unpack the new zip over the old folder, settings and ExifTool stay. Details — [Installation](https://github.com/rejgan318/geophotos#installation) in the README.

**New in 0.32.0**
- The *Edit* menu: *Copy Coordinates* (Ctrl+C), *Paste Coordinates* (Ctrl+V), *Delete Coordinates* (Ctrl+Del), *Take off the Strip* (Del), *Select All* (Ctrl+A). Before, these were only in Help. The keys work as before; in text fields they work with the text.
- The README tells which to choose: the installer does only three things beyond the zip (a folder in your profile, the Start menu, Windows *Apps*) and in return updates the program itself; the zip only tells about a new version.
- The README says plainly: *File → Open Folder…* always shows the whole folder — you pick one photo in it only to point at the folder. To work with only some photos of a folder, pick them in *File → Add Files…* (several at once), or open the folder and take the rest off the strip with Del.

Windows 10/11, 64-bit. Interface: English, Russian, Ukrainian.
