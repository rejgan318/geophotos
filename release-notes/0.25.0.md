The first public build of GeoPhotos — manual geotagging of photos and videos on a map for Windows, in the spirit of Lightroom's Map module.

**Install:** download `GeoPhotos-0.25.0-win-x64.zip` below, unpack it, run `GeoPhotos.exe`. The program is not signed: if Windows shows *"Windows protected your PC"*, click *More info → Run anyway*. If ExifTool is missing, click **Install for GeoPhotos** at the first start. Details — [Installation](https://github.com/rejgan318/geophotos#installation) in the README.

**New in 0.25.0**
- *File → Add Files…* (Ctrl+Shift+O), dropping files, and files on the command line add them to the strip without closing what is open — photos from several folders can be placed together.
- *File → Open Folder…* (Ctrl+O, formerly *Open Photo…*) opens a whole folder, as before.
- Del on photos without coordinates takes them off the strip; files on disk stay.
- The folder, the added files and the ones taken off come back after Refresh (F5) and at the next start.

Windows 10/11, 64-bit. Interface: English, Russian, Ukrainian.
