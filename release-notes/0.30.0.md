GeoPhotos 0.30.0 — an installer, and updates that come by themselves.

**Install:** download `GeoPhotos-Setup-0.30.0.exe` below and run it: it installs for you only, without administrator rights, adds GeoPhotos to the Start menu and, if you wish, to the desktop. Or take `GeoPhotos-0.30.0-win-x64.zip` and unpack it, as before. The program is not signed: if Windows shows *"Windows protected your PC"*, click *More info → Run anyway*. If ExifTool is missing, click **Install for GeoPhotos** at the first start. Details — [Installation](https://github.com/rejgan318/geophotos#installation) in the README.

**New in 0.30.0**
- **Installer** for Windows: welcome, folder (`%LOCALAPPDATA%\Programs\GeoPhotos` by default), a desktop shortcut if you leave the box ticked, *Run GeoPhotos* at the end; in English, Russian or Ukrainian, by the language of Windows. Uninstall from *Settings → Apps*; your settings stay.
- **Automatic updates** for the installed program: at start it looks for a newer version on GitHub and downloads it in the background; the status bar then says *"Version X is ready — restart"*. Click it to install now, or it is installed when you exit. The zip version only tells about a newer version and opens its release page. Turn the check off with `"checkUpdates": false` in the settings.
- The built program is hardened with Electron fuses: it cannot be run as plain Node.js, and loads only its own checked code.

The first automatic update will come with the next release after this one. If you use the zip and want updates to come by themselves, switch to the installer once: your settings are kept.

Windows 10/11, 64-bit. Interface: English, Russian, Ukrainian.
