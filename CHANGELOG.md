# Журнал изменений GeoPhotos

Что меняется в программе и в решениях — для пользователя, без подробностей кода (они — в истории git). Порядок: сверху новое. Как вести журнал — `make-project.md`, п. 8. Каждая фича — очередная подверсия (с 0.2.0); раньше разработка шла шагами.

## В работе

**Изменено**
- Подсказка у значков на миниатюре — само значение: у булавки координаты, у домика адрес, у горы высота, у видео длительность (было «Есть координаты», «Есть адрес»…).
- В начале README (на трёх языках) — вступление: зачем нужна программа — трек, фото с телефона и с фотоаппарата на одной карте, и чем она отличается от Lightroom.

**Решения**
- Подсказка у значков на миниатюре будет показывать само значение (координаты, адрес, высоту, длительность видео), а не «Есть координаты». Сделаем до тура.
- Будет меню «Правка»: копировать, вставить и удалить координаты, убрать из ленты, выбрать все — сейчас это есть только в справке, а что Ctrl+C копирует координаты, а не фото, не догадаться.
- Тур «как это работает» показывает только то, чего не видно в меню, — прежде всего перетаскивания. Первые карточки: из Проводника в окно, фото на карту, перенос маркера; последняя — фото на трек. Пояснение словами — по маленькому «?» в углу карточки, для тех, кому нужно.

## 0.30.0 — Установщик и автообновление — 2026-11-25

**Добавлено**
- Установщик для Windows (`GeoPhotos-Setup-<версия>.exe`): ставит программу только для вас, без прав администратора; приветствие, выбор папки, флажок «Ярлык на рабочем столе», запуск после установки; на русском, английском или украинском — по языку Windows. Удаление — через «Приложения» Windows, настройки остаются. Zip для распаковки — по-прежнему рядом.
- Автообновление: установленная программа при запуске узнаёт о новой версии, скачивает её в фоне и пишет справа в строке состояния «Версия X готова — перезапустить»; щелчок — перезапуск с установкой, иначе установится при выходе. Zip-версия сообщает о новой версии, щелчок открывает страницу релиза. Выключается настройкой `checkUpdates`.
- Защита собранной программы (предохранители Electron): её нельзя запустить как обычный Node.js или подменить её код.

**Решения**
- Пункта «Открыть в GeoPhotos» в контекстном меню Проводника не будет — ни в установщике, ни в программе.
- Будет тур «как это работает»: несколько карточек с короткими роликами неочевидных действий (перетаскивания, броски, двойные клики) — без текста, само действие объясняет себя. Сделаем позже. Подсказки с клавишами в строке состояния — не делаем: всё это уже есть в меню и в справке.

## 0.29.0 — Сборка релизов в облаке — 2026-11-25

**Добавлено**
- Релизы собираются в облаке GitHub (Actions) из открытого кода, а не на компьютере разработчика; GitHub заверяет каждый zip, и любой может проверить, что файл собран из этого репозитория и не изменён (`gh attestation verify`, README → Installation).
- В README — пошаговая сборка программы из исходников (раздел «Building from source»).
- Тесты идут в облаке при каждом изменении кода, на Windows и на Linux.

**Решения**
- «Заключительного этапа» больше нет: каждая версия рабочая и может оказаться последней, поэтому распространение делается сейчас, как обычные фичи. Ближайшие — сборка релизов в облаке GitHub с проверкой происхождения файлов и инструкция по сборке из исходников, затем установщик для Windows и автообновление.
- Linux — позже, когда его можно будет проверять (WSL); до этого сборки для Linux не выпускаются, но тесты под Linux будут идти уже со сборкой в облаке. macOS — по-прежнему только если появятся пользователи с Mac.

## 0.28.0 — Привязка по треку — 2026-11-25

**Добавлено**
- Привязка по треку. У текущего фото без координат на треке появляется красное кольцо — где вы были в момент съёмки (по времени снимка и его часовому поясу). Фото, брошенное на карту рядом с кольцом (или двойной клик рядом с ним), встаёт точно туда.
- Фото можно бросить в ленте на трек: каждое получит своё место на треке по времени съёмки, координаты заменяются; снятые вне трека не меняются.
- Пока фото тянут по ленте, миниатюры, на которые бросить нельзя (например, трек другого дня), бледнеют.

## 0.27.0 — Скорость чтения папки — 2026-11-24

**Изменено**
- Папка открывается в несколько раз быстрее: 122 снимка телефона — 0,6 с вместо 4, папка из 1 713 RAW — 7 с вместо 39. Программа не дочитывает файлы до конца и читает их несколькими процессами — по числу файлов, но не больше числа ядер процессора.

**Решения**
- Кэш миниатюр на диске не нужен: миниатюры строятся быстро и только для видимой части ленты. Показ ленты по частям, пока читается папка, тоже не нужен — чтение и так быстрое.

## 0.26.0 — Треки — 2026-11-24

**Добавлено**
- Треки: GPX, KML, KMZ, FIT, TCX и GeoJSON — из открытой папки, через «Добавить файлы…» и перетаскиванием. В ленте трек стоит по времени начала, с миниатюрой-силуэтом своего цвета и значком «трек»; в счётчик и фильтры не входит. На карте — линия (цвета по списку из настроек), путевые точки — флажки цвета трека с названиями (видны при наведении и при крупном масштабе). При наведении на линию — время ближайшей точки по месту трека, высота, пульс, скорость, каденс, температура, мощность — что есть в файле.
- Выбор трека: клик в ленте или по линии на карте; выбранный трек толще; двойной клик и C — показать трек целиком.
- Просмотр трека (пробел на треке): карта слегка затемнена и неподвижна, виден только этот трек; слева сводка — начало и конец, расстояние, время всего и в движении, остановки, средняя и наибольшая скорость, набор и сброс высоты, высота, пульс, число точек, устройство; внизу профиль высоты и, если есть, пульса; при наведении на профиль по треку бежит точка.
- Ctrl+Del — удалить у выбранных фото координаты, адрес и высоту.

**Исправлено**
- При добавлении нескольких треков выбранными становились все → теперь выбираются добавленные фото, а если добавлены только треки — первый из них (трек выбирается один).
- Выход из просмотра трека возвращал карту к треку, с которого начали, даже если в просмотре выбрали другой → теперь карта показывает текущий трек целиком (или текущее фото).

**Изменено**
- «Добавить файлы…» открывается в папке, из которой файлы добавляли в прошлый раз (и после перезапуска), а не в открытой папке.
- Del теперь всегда убирает выбранные фото или трек из ленты; если у фото есть несохранённые изменения — сначала вопрос. Удаление координат — Ctrl+Del.

**Решения**
- Треки будут: в 0.26.0 — показ (GPX, KML, KMZ, FIT, TCX, GeoJSON) в ленте и на карте, путевые точки, подсказка на линии, просмотр трека по пробелу со сводкой и профилем высоты; в следующих версиях — помощь в привязке фото по времени. Прежний отказ от треков отменён.
- Del будет всегда убирать фото или трек из ленты (с вопросом, если есть несохранённые изменения), а удаление координат переедет на Ctrl+Del — одна клавиша, одно действие.
- Репозиторий открыт. Готовая программа — zip в GitHub Releases (первый — 0.25.0); установка — распаковкой, инструкция в README. Мастер установки и автообновление — по-прежнему на заключительном этапе.

**Добавлено**
- В README — раздел «Installation» (скачать, распаковать, первый запуск, exiftool, обновление, удаление) и возможности 0.25.0.
- README на русском (`README.ru.md`) и украинском (`README.uk.md`) — всё для пользователя, кроме раздела для разработчиков; переключатель языков вверху каждого.

## 0.25.0 — Папка и отдельные файлы — 2026-11-24

**Добавлено**
- «Файл → Добавить файлы…» (Ctrl+Shift+O): выбранные файлы добавляются в ленту к тому, что в ней уже есть, — можно собрать ленту из разных папок. Перетаскивание файлов из Проводника и файлы в параметрах запуска делают то же; перетаскивание папки открывает её, как раньше.
- Del у фото без координат убирает их из ленты (файлы на диске не меняются).
- Добавленные файлы, убранные из ленты фото и папка восстанавливаются при следующем запуске; F5 перечитывает и папку, и добавленные файлы.

**Изменено**
- «Открыть фото…» называется «Открыть папку…» (Ctrl+O); работает так же — выбранное фото открывает свою папку.
- Перетаскивание одного фото из Проводника больше не открывает его папку, а добавляет фото в ленту.
- Фото не из открытой папки показываются с полным путём.

**Решения**
- Лента собирается из папки и отдельных файлов. Открытие папки («Открыть папку…», Ctrl+O — бывший «Открыть фото…»; перетаскивание папки; параметр запуска) начинает всё заново, как раньше. «Добавить файлы…» (Ctrl+Shift+O), перетаскивание файлов и файлы в параметрах запуска добавляют их в ленту, ничего не сбрасывая, — можно собрать ленту из разных папок. В «Недавние» попадают только папки.
- Del у фото без координат (или повторный Del) убирает их из ленты; файлы на диске не меняются. Убранные файлы папки не возвращаются по F5 и при следующем запуске.
- Термины: «папка» (не «директория»); «фото» — общее слово для фото и видео.
- Треки (GPX и другие) — будут обсуждаться после этой версии; прежний отказ от них пересматривается.

## 0.24.0 — «Живые» фото — 2026-11-22

**Добавлено**

**Решения**
- Стрелки ← → в открытом меню не переключают пункты верхнего уровня: так устроено меню самого Electron (известная ошибка, не исправлена), в программе это не исправить.

## 0.22.0 — Видео: привязка — 2026-11-22

**Добавлено**
- Видео привязываются так же, как фото: перетаскиванием на карту и внутри ленты, маркером, двойным щелчком по карте, Ctrl+V, Del; получают адрес и высоту; пакетный режим тоже обрабатывает видео.
- Куда пишется: MOV, MP4, M4V, 3GP — в сам файл, туда, где координаты хранят телефоны (их видят Google Фото, Apple Photos и другие программы); адрес — в XMP файла. AVI, MPG, MTS, MKV, WMV и другие — в XMP рядом (MVI_0001.xmp), сам ролик не меняется.
- Время изменения видеофайла при записи сохраняется — у некоторых роликов это единственная дата.

**Решения**
- Координаты из трека (GoPro, регистраторы) удалить нельзя — Del для такого ролика даёт ошибку записи; новые координаты пишутся поверх и читаются первыми.
- Проводник Windows читает записанные в MOV и MP4 координаты так же, как координаты телефона, но в своём окне их не показывает (столбцов широты и долготы в Windows 11 нет). FastStone Image Viewer координаты видео не показывает вообще, в том числе записанные телефоном.

## 0.21.0 — Строка состояния, высота 0, поиск exiftool — 2026-11-22

**Изменено**
- Строка состояния: имя текущего фото — светлым, дата, размер файла и (у видео) длительность — тем же цветом приглушённо, через тусклую точку: `IMG_3381_DxO.jpg   2010-07-03 21:19:56 · 6,4 МБ`. Размер — новый.
- Пометки «(дата файла)» и «(из имени файла)» убраны везде — в строке состояния, подсказке и режиме просмотра.
- Даты — в региональном формате Windows, как в Проводнике («03.07.2010 21:19:56»), а не «2010-07-03».

- Высота 0 у фото с координатами проверяется, пока включено «Сервис → Получать высоту» (и в пакетном режиме): если рельеф в точке выше 10 м над морем (или ниже −10), 0 заменяется высотой рельефа — как несохранённое изменение. У берега моря 0 остаётся.
- Если exiftool не найден по пути из настроек, программа ищет его сама в обычных местах (рядом с программой, установщик exiftool для Windows и winget, Chocolatey, Scoop, папка Windows). Не нашла — в окне кнопки «Скачать exiftool», «Открыть файл настроек» (создаётся, если его ещё нет) и «Закрыть». Раньше было только «OK», а файла настроек при первом запуске ещё не было.

**Решения**
- Привязка видео переносится на 0.22.0.
- exiftool по-прежнему не входит в программу — его ставят отдельно.

## 0.20.0 — Видео: показ — 2026-11-22

**Добавлено**
- Видео в ленте и на карте вместе с фото: MOV, MP4, M4V, 3GP, AVI, MPG, MPEG, VOB, MTS, M2TS, MKV, WMV, FLV и другие, которые читает exiftool. Миниатюра — та же, что у Проводника Windows (ffmpeg не нужен); если Windows кадр не отдаёт — заглушка. Значок «плёнка» в верхней строке миниатюры; в подсказке — «Видео, 0:47».
- Режим просмотра (пробел) для видео: крупный кадр и кнопка «Открыть в проигрывателе» — ролик открывается программой Windows по умолчанию. Проигрывания в самой программе нет.
- Координаты видео читаются: из метаданных телефона (QuickTime), XMP рядом, а если их нет — первая точка трека (GoPro, регистраторы, дроны, Sony; такие ролики читаются дольше).
- «Открыть фото…» показывает и видео.
- Дата из имени файла (`20190816_192927`, `VID_20250426_101211`, `1998 03 19 …`) — для фото и видео без даты съёмки, раньше времени изменения файла; в подсказке помечена «(из имени файла)».

**Решения**
- Время съёмки видео — только для порядка ленты и показа, никуда не пишется. Телефоны пишут время в UTC — оно переводится в местное время места съёмки по координатам; камеры (Canon, Olympus и др.) пишут местное — берётся как есть (проверено по фото той же камеры); пояс, указанный в файле, важнее (ТЗ, п. 4.2).
- Видео пока только показываются: перетащить их, вставить или удалить координаты, получить адрес и высоту нельзя — это 0.21.0. Фото, брошенное на видео с координатами, получает их; Ctrl+C с видео работает.
- Запись координат видео (0.21.0): MOV, MP4 и родственные — в сам файл, остальные — в XMP рядом.

## 0.15.0 — Адрес по координатам — 2026-11-11

**Добавлено**
- Меню «Сервис» с флажком «Получать адрес». Пока он включён, программа получает адрес (страна, код страны, область, город, улица с домом) для всех фото открытой папки, у которых есть координаты, но нет адреса, — в том числе сразу после перетаскивания на карту. Названия — на языке интерфейса. Сервис — Nominatim (по умолчанию публичный, не чаще запроса в секунду; адрес и пауза — в настройках `geocode`). Фото в одной точке получают адрес одним запросом. Флажок запоминается между запусками.
- В строке состояния — сколько адресов осталось получить и примерно за какое время.
- Если сохранить, пока адреса ещё получаются, — вопрос: «Подождать и сохранить», «Сохранить без них», «Отмена».
- Значок-домик в верхней строке миниатюры, рядом со значком координат, — у фото есть адрес. Места в этой строке закреплены: дальше будут высота и ещё одно место в запас. Сам адрес — в режиме просмотра фото (пробел) под именем, датой и координатами (координаты там тоже новые).
- Адрес, уже записанный в файле (например, Lightroom), читается и показывается.

**Изменено**
- При смене координат прежний адрес фото удаляется — при включённом флажке вместо него получается новый. Адрес пишется в XMP (как в Lightroom); старые названия мест в IPTC при записи удаляются, чтобы не расходились.
- Поиск мест и получение адресов делят ограничение «не чаще запроса в секунду» к одному серверу.
- В окне «О программе»: «Привязка фото к карте» — без «Ручная» и без точки в конце.
- Лог называется `geophotos.log` (был `main.log` — имя по умолчанию библиотеки); запасные — `geophotos-<дата>-<время>-<процесс>.log`. Файлы со старым именем удаляются при запуске, об этом — строка в новом логе.
- «Открыть файл настроек» перенесён из меню «Файл» в «Сервис», там же новый пункт «Открыть папку логов». Из окна «О программе» ссылки на настройки и логи убраны, ссылки на лицензии остались.

**Добавлено**
- Выделение в ленте: клик, Ctrl+клик, Shift+клик (Ctrl+Shift+клик добавляет диапазон), Ctrl+A. Маркеры всех выделенных фото красные; карта и строка состояния следуют за последним выбранным фото, в строке состояния — «Выбрано: N».
- Перетаскивание из ленты на карту: выделенные фото получают координаты точки, несколько фото — одну точку. Если тащить невыделенное фото, переносится только оно (как в Lightroom).
- Перетаскивание внутри ленты на фото с координатами: перетащенные фото получают его координаты. На фото без координат бросить нельзя.
- Перетаскивание маркера на карте: меняются координаты всех фото в точке этого маркера.
- Поиск места на карте (поле слева вверху): запрос по Enter, список результатов (стрелки ↑ ↓ и Enter тоже работают), выбор переносит карту и ставит синюю метку-кольцо. Фото, брошенное рядом с меткой (до ~24 пикселей), встаёт точно на неё. «×» очищает поиск и метку. Не чаще одного запроса в секунду, программа называет себя сервису.
- Отметка в ленте «изменено, не сохранено»: значок-карандаш (жёлтую рамку убрали по выбору пользователя — перегружала ленту); то же в подсказке и строке состояния. Если вернуть фото точно в прежнюю точку, отметка снимается.
- Счётчик «Изменено» в строке состояния и `*` в заголовке окна.
- «Файл → Save» (Ctrl+S) и «Save Selected»: пункты доступны, только когда есть что сохранять. Если запись идёт дольше доли секунды — окно «Сохранение n из N». По окончании — «Сохранено: N» в строке состояния; если что-то не записалось — окно со списком файлов и причин, их отметка «изменено» остаётся. После записи координаты перечитываются из файлов.
- Куда пишется: JPEG, HEIC, DNG, PNG, TIFF и др. — в EXIF самого файла; если во встроенном XMP или в XMP рядом уже есть координаты — туда тоже. CR2 и другие RAW — только в `имя.xmp` рядом: существующий дополняется (всё прежнее содержимое остаётся), отсутствующий создаётся. Копий `*_original` нет.
- Предупреждение о несохранённых изменениях при выходе (меню, крестик, Alt+F4) и при открытии другой папки: «Сохранить», «Не сохранять», «Отмена».
- В логе — каждая запись: файл, старые и новые координаты, куда записано; ошибки записи; отказ от несохранённых изменений.
- Фильтр ленты (по предложению пользователя): счётчик в строке состояния стал тремя мини-кнопками: значок и число (значок «фото» — всего, булавка — с координатами, карандаш — изменено; слова — в подсказке). Клик показывает только эти фото, включённый фильтр обведён цветом своего значка («всего» — белым), повторный клик снимает фильтр. Фильтр действует и на маркеры карты (по замечанию пользователя: сначала он был только для ленты): у скрытых фото маркеров нет; по клику на кнопку фильтра карта показывает все его фото (правка и сохранение карту не двигают); перетаскивание маркера переносит только видимые фото в его точке. Фильтр обновляется сразу: после «Save» фото уходят из «Изменено». Ctrl+A, Shift+клик и стрелки работают по видимым фото.

- Фильтр, под который не попадает ни одно фото, недоступен (кнопка и пункт меню); если включённый фильтр опустел (например, «Изменено» после сохранения), включается «Всего».
- В папке всегда выбрано фото: при открытии папки — первое фото ленты; последний выбор Ctrl+кликом не снимается; если фильтр скрыл выбранные — первое видимое.
- Запуск без параметра открывает папку и фото прошлого сеанса (они запоминаются при выходе). Нет папки — программа открывается без папки; нет фото — папка с первым фото; только запись в логе.
- Режим просмотра фото: пробел или «Вид → Просмотр фото». Фото на месте карты, вписано целиком, имя и дата в углу; лента и строка состояния остаются, ← → листают. RAW, DNG, HEIC — по встроенному превью.
- Меню «Вид» в готовой программе: «Просмотр фото» и три фильтра (те же, что кнопки в строке состояния).

**Исправлено**
- Значок «изменено» в ленте был крупнее и ярче значка координат → такой же тёмный кружок того же размера, карандаш жёлтый.
- Русский файл языка был испорчен при правке пункта «Сохранить выбранные» — русский интерфейс не загрузился бы. Исправлено; тест теперь проверяет, что в файлах языков нет синтаксических ошибок.

**Решения**
- Если при выходе или открытии другой папки выбрано «Сохранить», а часть файлов записать не удалось, программа остаётся в текущей папке — чтобы не потерять эти изменения.
- Файл только для чтения проверяется до вызова exiftool: иначе exiftool оставляет рядом временный файл `*_exiftool_tmp`. Такой файл от прошлых сбоев удаляется перед записью.
- Координаты хранятся с точностью 7 знаков после запятой (около 1 см).
- Метка найденного места лежит под маркерами фото, чтобы брошенное на неё фото было легко взять снова.
- Известное ограничение: запись меняет дату изменения файла, поэтому фото без даты съёмки (их место в ленте — по дате файла) после повторного открытия папки могут переместиться в конец ленты.
