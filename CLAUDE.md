# CLAUDE.md

Этот файл содержит указания для Claude Code (claude.ai/code) при работе с кодом в этом репозитории.

## Проект

**GeoPhotos** — приложение для Windows на Electron + Node.js для ручной привязки фото к карте (по образцу модуля Map в Lightroom). Git-репозиторий, удалённый — приватный на GitHub. Версия 0.24.2; каждая новая фича — очередная подверсия (`make-project.md`, п. 5), текущее состояние — в разделе «Статус» `make-project.md`.

## Команды

- `npm run dev` — запуск при разработке.
- `npm run build` — готовая программа: `dist/win-unpacked/GeoPhotos.exe`.
- `npm run typecheck` — проверка типов (main/preload/shared/tests и окно отдельно).
- `npm test` — unit-тесты; `npm run test:integration` — тесты с настоящим exiftool.
- Один тест: `npx vitest run tests/unit/<файл>.test.ts`.

Код: `src/main` (main-процесс), `src/preload` (мост, тип API в `api.d.ts`), `src/renderer` (окно), `src/shared` (общее, импорт как `@shared/...`). Подробности — `make-project.md`, п. 3.

## Документы

- `tz.md` — техзадание: итоговые требования, история версий и будущие фичи (п. 9), что не нужно делать. Главный источник требований; читать перед проектированием любой функции. При изменении требований обновлять этот файл.
- `tz-config.md` — обязательное ТЗ на устройство конфигурации программы.
- `make-project.md` — как создавать и развивать код: технические решения, структура, порядок работы над фичей и версиями, тесты, статус. Читать в начале каждой сессии и следовать ему; статус в нём обновлять по ходу работы.
- `CHANGELOG.md` — журнал изменений для пользователя; вести по `make-project.md`, п. 8.
- `tz_questions.md` — история вопросов и ответов, из которой собран `tz.md`. Использовать только для выяснения, почему принято решение. Если он расходится с `tz.md`, спросить пользователя.
